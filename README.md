# Timed End Unlock

A Quilt/Fabric-API Minecraft mod that controls and schedules access to The End dimension.

## Requirements

- **Minecraft:** `26.3`
- **Java:** `25`
- **Quilt Loader:** `>= 0.30.2`
- **Fabric API:** `0.165.0+26.3`

## Building

```bash
./gradlew build
```

Built JAR artifacts are output to `build/libs/`.
